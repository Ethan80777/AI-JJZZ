# 工具接入查證

2026-10-15：第一期只提供本機人工製作工作區、匯出及資產匯入。目錄品牌是候選工具，不代表已整合或已確認模型能力。官方文件請求曾遭雲端代理 HTTP 403，故不填造查證日期、價格、模型 ID、最大長度或授權保證。

使用者可以編輯目錄、選擇人工製作工具及開啟 HTTPS 官網。沒有遠端生成執行器，沒有 API 金鑰欄位。`adapter-contract.ts` 只定義第二期 validate／estimate／submit／poll／cancel／collect 契約，沒有模擬成功回傳。

後續每個供應商須單獨查證：官方來源、日期、輸入輸出、模型與參數、費用與幣別、授權地域及期限、取消／重試／限流行為，再以使用者授權的憑證實測。
