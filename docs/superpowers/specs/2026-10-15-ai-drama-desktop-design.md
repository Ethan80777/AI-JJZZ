# AI 劇集工業化製作平台：桌面版設計規格

狀態：架構方向已確認；本規格待使用者審閱。
日期：2026-10-15
目標儲存庫：Ethan80777/AI-JJZZ

## 1. 目的與已確認需求

服務個人創作者與小型製作團隊，從題材、小說、劇本一路管理到成片、跨語區版本、發行及復盤。使用者已確認採用 Windows／macOS 獨立桌面應用程式，以 Electron + React 實作；安裝後雙擊 `.aidrama` 檔案，即可開啟對應專案及製作畫布。

所有五幕14步依流程順序出現在同一張可縮放畫布。點擊幕次可展開或收合子節點，點擊步驟開啟編輯面板；使用者可增減、修改節點並更換生產工具。專案不限定中文母版，任意來源語言均可建立其他語言版本。

主要成功條件：使用者能建立專案、編輯14步的實際交付物、保存及重新開啟、管理資產與版本，並明確區分人工工作、真實工具執行及尚未接入的能力。

### 需求來源與證據界線

- 依據使用者提供的兩套「五幕14步」、製作 SOP、G1–G8 門禁、成本假設表、分鏡表、角色聖經及語區資料合併整理。
- 原文提及已存在的 Skill、試算表及參考文件，並不代表這些檔案實際存在於儲存庫。實作須建立所需模板，不能宣稱已安裝。
- 目前儲存庫沒有既有應用程式；桌面平台屬新建專案。
- 對 React Flow、ComfyUI、ElevenLabs、YouTube 文件及原始影片的外網請求曾收到代理 `403`；尚未完成外部資料核實。
- 模型名稱、版本、價格、支援語言、生成時長、商用權利與發行資格，須以接入當時可查證的官方文件為準。工具目錄保留來源網址、查證日期及狀態。
- 原文中的市場偏好、留存率與成本數字作為可編輯假設，不能當作保證結果或所有地區通用規則。

## 2. 分期邊界

完整產品涵蓋以下三個子專案。本規格詳細定義第一期及其擴充契約；第二、三期須在接入服務與權限明確後另行設計及驗收。

### 第一期：可使用的桌面製作工作台

包含桌面入口、專案格式、完整五幕14節點、各節點結構化編輯器、手動交付物管理、資產庫、語言版本、工具目錄與綁定、流程狀態、審核紀錄、成本計算、匯入匯出及備份。

Agent 在此階段提供確定性的流程導航、缺項檢查、依賴追蹤與交付物打包。沒有配置並通過測試的模型接入，不顯示「AI 已生成」。工具可標示為人工操作或待接入。

第一期不以實際生成整部劇、直接操作所有第三方網站、自動投廣告或商店簽署發行為驗收前提。這些能力屬後續子專案，仍保留對應節點及可工作的人工流程。

### 第二期：生成與影音生產

接入經驗證的文字、圖像、影片與配音供應商；實作持久任務執行器及 FFmpeg 合成。每一類先完成一個真實接入並驗收，再擴充其他工具。遠端 ComfyUI 亦可作為接入選項；不要求第一期在使用者電腦安裝 GPU 模型。

### 第三期：發行與數據整合

依平台實際 API、帳號權限及審核要求逐個接入，支援上傳、排程、發布狀態及數據匯入。平台不提供適用 API 時，提供發行包與人工提交流程。廣告預算及公開發布須有明確操作確認。

## 3. 桌面架構

| 元件 | 職責 | 邊界 |
| --- | --- | --- |
| React + TypeScript renderer | 畫布、編輯器、資產檢視、任務及工具設定 | 不直接存取檔案系統、金鑰或任意 Node API |
| Electron preload | 暴露具型別且限制用途的 IPC 介面 | 每個呼叫具參數驗證，不提供通用 shell 執行 |
| Electron main | 專案開啟、儲存、路徑管理、系統整合、安全憑證 | 執行可信任的應用程式邏輯 |
| 專案儲存層 | SQLite 資料、資產檔案、修訂及備份 | renderer 透過服務介面操作 |
| 流程核心 | 節點契約、依賴、審核、失效傳播、交付物驗證 | 不依賴特定模型供應商 |
| 工具接入層 | 能力描述、參數驗證、請求與結果轉換 | 各供應商獨立 adapter |
| 背景執行器（第二期） | 遠端任務追蹤、媒體處理、取消與恢復 | 避免阻塞視窗；不信任模型輸出的可執行指令 |

採用 React Flow 作為候選畫布元件，安裝時驗證版本及授權。程式碼依專案、流程、資產、在地化、工具接入、桌面橋接分模組；不將所有節點寫進單一元件。

Electron 使用 `contextIsolation`、停用 renderer 的 Node integration，並採取限制來源的 CSP。外部工具網址以系統瀏覽器開啟，不載入具特權的應用程式視窗。

## 4. 專案檔與桌面入口

### 檔案結構

```text
我的劇集.aidrama              # UTF-8 JSON manifest，可雙擊
我的劇集.assets/
  project.sqlite             # 交付物、版本、節點、審核與設定
  media/                     # 已匯入的圖像、影片、聲音與憑證
  exports/                   # 匯出的劇本、分鏡、字幕與發行包
  backups/                   # 一致性備份
```

Manifest 包含格式版本、專案 UUID、顯示名稱及相對資產目錄。載入時檢查格式、檔案大小與路徑；預設拒絕跳出專案目錄的路徑及不安全符號連結。若資產目錄遺失，顯示修復定位操作，不建立空白資料覆蓋原專案。

移動一般專案須同時移動 manifest 與資產目錄；「匯出完整專案」產生可攜式 `.aidrama.zip`，包含 manifest、SQLite 一致性快照、已管理資產及內容雜湊，不包含金鑰、快取或機器專屬路徑。第一期不依賴外部連結資產，匯入時複製至專案目錄。

匯入壓縮檔時驗證路徑穿越、符號連結、項目數及展開大小，先寫入暫存目錄，通過驗證後才成為正式專案。匯出不得僅複製使用中的 SQLite 主檔而遺漏 WAL 資料。

### 開啟與保存行為

- Windows 以安裝程式註冊 `.aidrama` 關聯，處理啟動參數與 second-instance 事件。
- macOS 註冊文件類型並處理 open-file 事件，包括應用程式尚未完成初始化的情況。
- 已開啟的相同專案切回原視窗；另一個專案可開啟新視窗。同一專案僅允許一個寫入者。
- 編輯資料自動保存，介面顯示未儲存、儲存中、已儲存或失敗；失敗時保留編輯內容及重試操作。
- JSON manifest 原子替換；資料庫寫入使用交易。關閉視窗前處理尚未完成的儲存。
- 新格式由版本化 migration 升級，先建立備份；無法讀取的較新格式以明確訊息拒絕，禁止猜測後覆寫。
- 備份預設保留最近10份成功的快照，保留數可設定；只有新備份驗證成功才清理過期備份。

## 5. 畫布與節點互動

首頁提供建立專案、開啟檔案及最近專案。專案畫布預設由左至右排列五幕，每幕由上至下排列對應步驟，使用節點連線表達資料依賴。

畫布支援平移、縮放、符合視窗、搜尋、幕次收合及選取定位；提供等價的清單導航與鍵盤操作。編輯面板開啟時保留畫布位置及未儲存內容。

節點共有六區：輸入、工作內容、工具、輸出、檢查與歷史。每個節點都能直接編輯交付物，不只顯示說明文字。工具選擇顯示能力、連接狀態、參數、價格來源及版本。

使用者可加入文字、表格、資產、檢查清單類型的自訂節點。第一期不支援安裝可執行任意程式碼的第三方外掛。刪除有依賴的節點前列出影響，提供封存；移動畫布位置不改變執行依賴。

標準14步具有穩定識別碼；可停用或封存，但必填輸入及 Gate 不能因視覺上隱藏節點而自動通過。流程模板可複製與版本化，既有專案固定使用原模板版本，更新需顯示差異。

## 6. 五幕14步的統一契約

| --- | --- | --- | --- |
| 一／01 市場驗證 | 市場、競品、成本假設 | 競品表、資料來源、成本／收入情境、ROI | 假設可追溯；區分估計與實測 |
| 一／02 題材定位 | 市場分析、創作方向 | 題材卡、受眾、國家與語言優先級 | 目標市場、故事衝突與預算完整 |
| 二／03 小說創作 | 原創構想或有權使用的原著 | 世界觀、人物小傳、章節、分集大綱 | 原著權利紀錄、主線及角色一致性 |
| 二／04 劇本改編 | 章節、大綱與人物 | 分集劇本、動作、對白、鉤子及卡點表 | 時長、未解伏筆、承接關係 |

| 三／08 AI影片 | 關鍵幀、提示詞、參考資產 | 鏡頭片段、生成紀錄、可用率及廢片標記 | 檔案可讀、實際時長、人工畫面審核 |

| 四／10 剪輯合成 | 合格片段、聲音、字幕 | 鏡頭排序、剪輯決策表、匯入母版及輸出規格 | 缺失素材、母版時長與規格 |

| 五／14 數據復盤 | 匯入的播放／付費／成本數據 | 指標表、逐集留存、素材比較及改進清單 | 指標分母、期間、幣別及來源一致 |

分鏡採兩套資料的欄位聯集：集／場／鏡、鏡頭組、場景、站位、景別、運鏡、動作、台詞、音效、時長、情緒、參考資產、正負提示詞、工具／模型版本、狀態、退件原因及備註。合併鏡頭組時保留原鏡頭識別碼。

第一期各節點支援手動輸入、資產匯入與交付物保存；第10步提供剪輯決策表及成片匯入，完整時間軸影音引擎與 FFmpeg 合成屬第二期。

## 7. 資料模型與版本依賴

主要實體：Project、WorkflowTemplate、Act、StepInstance、Episode、Scene、Shot、ShotGroup、Character、Asset、ArtifactRevision、LocaleVariant、ToolDefinition、ToolBinding、Task、GateReview、CostEntry、ReleaseRecord、MetricRecord。

每個實體使用穩定 UUID。每份交付物與資產都記錄建立時間、來源、語言、修訂、相關角色／鏡頭、權利狀態及選用版本。檔案記錄內容雜湊，避免把不同內容當成同一資產。

下游交付物引用確切上游修訂，不引用會悄悄改變的「最新版」。修改已使用的角色、劇本或關鍵幀後，受影響下游標記「來源已更新／待重審」，不立即刪除成果或自動付費重生成。只有受依賴影響的成果失效，不宣稱換模型必然需要全片重做。

成本記錄保留原幣別、單位、數量、單價及估算／實際狀態。轉換幣別時記錄匯率、日期與來源。ROI 定義為 `(收入－總成本)／總成本`；另顯示 `收入／總成本` 的回收倍數，避免混用。零成本、缺值與不完整收入不能產生誤導性百分比。

## 8. 狀態與 G1–G8 審核

節點狀態：未開始、編輯中、待審、通過、退回、來源已更新、已封存。任務狀態另行管理，避免「任務成功」等同於「內容通過」。

| Gate | 對應成果 | 放行條件 |
| --- | --- | --- |
| G1 | 01–02 立項 | 題材、資料來源與預算已審核 |
| G2 | 03–05 內容 | 劇本、分鏡與引用檢查通過；未有的正式視覺資產可先引用角色定義 |
| G3 | 06 視覺聖經 | 參考資產齊全且人工確認一致性，凍結所選版本 |
| G4 | 07 關鍵幀 | 對應鏡頭的關鍵幀已審核 |
| G5 | 08–09 影音素材 | 對應素材可用且聲音／授權檢查通過 |
| G6 | 10 母版 | 剪輯、字幕與技術規格已審核 |
| G7 | 11 語言版本 | 術語、配音、字幕與文化適配已審核 |
| G8 | 12 發行審核 | 目標市場／平台的權利及內容清單通過 |

Gate 具有專案、集數或語言版本的適用範圍，允許先完成試播集而非等待全劇。所有節點允許提前草擬；受控生產及放行時才檢查前置條件。草稿不可繞過 Gate 成為可發布版本。

審核保存操作者、時間、備註、修訂與清單結果。第一期為本機單使用者，操作者名稱屬工作紀錄，不冒充具身份驗證或法律效力的電子簽章。

## 9. 工具與任務接入契約

工具按文字、圖像、影片、語音、音樂、剪輯、翻譯、發布、分析分類。工具目錄可保留使用者指定的候選品牌，但須顯示「待查證」「人工操作」「未配置」「已連接」等真實狀態。

Adapter 描述包括 provider、能力、允許的模型 ID、輸入輸出 schema、參考資產限制、語言、費率來源及文件網址。替換工具先檢查相容性，不能把舊供應商的參數直接傳給新供應商。模型 ID、時長及解析度限制不能由名稱猜測。

第二期統一介面：validate、estimate、submit、poll、cancel、collect。不是所有供應商都支援取消或估價，介面須顯示能力缺口。

任務在呼叫服務前保存輸入快照與本機任務 ID；取得遠端 ID 後立即持久化。重啟優先查詢原任務，不能直接重送可能收費的請求。提交後連線中斷且供應商不支援冪等或查詢時，標記「結果未知」，由使用者確認後才能重送。

任務狀態：排隊、執行中、取消中、成功、失敗、已取消、結果未知。取消遠端任務不保證停止計費；若遠端無取消能力，保留追蹤並清楚顯示。

API 金鑰由主程序存入系統安全憑證機制，日誌遮蔽憑證；不寫入專案、匯出包、renderer 儲存或原始碼。若安全儲存不可用，不靜默降級為明文。

## 10. 多語與文化適配

分開儲存來源語言、目標語言／地區、發行市場及字幕方向。預設目錄涵蓋簡繁中文、英語、法語、西語、德語、俄語、日語、韓語、阿拉伯語、土耳其語，以及印尼語、馬來語、泰語、越南語、菲律賓語；支援新增其他 BCP 47 語言標籤。

語言版本由任意來源版本分支，保留共同故事及資產引用。字幕／配音改編與角色／場景視覺重製為不同操作，分別估算成本。不能宣稱跨語重製零成本。

術語表包含角色名稱、地名、稱謂、敬語、讀音與禁用譯法。語區建議可編輯、有資料來源，不把地域刻板印象強制套用至人物或題材。阿語提供 RTL、混合數字及標點預覽；輸出至少包含 UTF-8 SRT、VTT 與 JSON。

## 11. 權利與發布

將原文的「雙洗」整理為有權使用素材的兩階段改編：先提取故事與戲劇節點，再改寫成影視大綱。改名、重繪、諧音或提示詞正向標語均不作為版權授權或合規證明。

授權紀錄覆蓋原著、人物肖像、聲音、音樂、字型及其他素材；未審、已取得、到期及限制地區分開記錄。政策檢核依實際國家與平台建立，不把整個語區視為單一法律制度。

## 12. 故障處理

- 磁碟不足、權限拒絕或儲存失敗：保留未保存內容並阻止誤報成功。

- 供應商超時／限流：顯示重試時間；依錯誤類型處理，不盲目重複付費任務。
- 無憑證或服務未接通：仍可編輯專案及匯出人工操作包，生成按鈕顯示所缺條件。
- 使用者修改被凍結資產：建立新修訂並計算影響，不覆寫已放行版本。
